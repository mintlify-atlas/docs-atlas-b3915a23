Neon supports a wide range of Postgres extensions — from vector search and geospatial data to full-text search, job scheduling, and cryptography. You can install most extensions with a single SQL statement, and Neon keeps extension versions up to date as new releases become available.

## How to enable an extension

Most extensions can be installed with the standard `CREATE EXTENSION` statement. Run it from the [Neon SQL Editor](https://console.neon.tech) or any connected Postgres client such as `psql`.

```sql
CREATE EXTENSION <extension_name>;
```

A few extensions have installation notes — for example, `pgvector` uses the name `vector`, and `uuid-ossp` requires double quotes around the name. See the details for each extension below or in the per-extension guides.

<Note>
Some extensions require a preloaded shared library and additional setup before you run `CREATE EXTENSION`. Notable examples include `pg_cron` (requires setting `cron.database_name` via the API) and `pg_repack` (available on paid plans, requires a support ticket). Check the notes column in the extension table or the dedicated guide for any extension you plan to use.
</Note>

## How to check available extensions

To see all extensions available on your current Postgres version, run:

```sql
SELECT name, default_version, comment
FROM pg_available_extensions
ORDER BY name;
```

To check which extensions are already installed in your database, query `pg_extension`:

```sql
SELECT extname, extversion FROM pg_extension;
```

## How to update an extension

When Neon releases a new extension version, you can update an installed extension using `ALTER EXTENSION`:

```sql
ALTER EXTENSION <extension_name> UPDATE TO '<new_version>';
```

For example, to update `pgvector` to version 0.8.0:

```sql
ALTER EXTENSION vector UPDATE TO '0.8.0';
```

<Note>
A compute restart is required before a newly released extension version becomes available for installation or update. Computes that use [scale to zero](/features/scale-to-zero) restart automatically when idle. If your compute is always active, you may need to trigger a manual restart via the [Neon API](https://api-docs.neon.tech/reference/restartprojectendpoint).
</Note>

## Extensions by category

The table below lists supported extensions grouped by category. Extension versions may differ by Postgres version. A dash (`-`) means the extension is not yet supported for that version.

### Vector and ML

| Extension | Description |
| --------- | ----------- |
| [pgvector](/extensions/pgvector) | Store vector embeddings and run similarity searches (L2, cosine, inner product, L1, Hamming, Jaccard). Install with `CREATE EXTENSION vector;` |
| [pg_tiktoken](https://github.com/kelvich/pg_tiktoken) | Count tokens using OpenAI's tiktoken tokenizer from SQL. |
| [pgrag](https://github.com/neondatabase/pgrag) | Experimental RAG pipeline extension for embedding generation and reranking. Requires `SET neon.allow_unstable_extensions='true';` before installing. |
| [cube](/extensions/overview) | Multidimensional cube data type, often used as a dependency for `earthdistance`. |

### Geospatial

| Extension | Description |
| --------- | ----------- |
| [postgis](/extensions/postgis) | Full geospatial support — geometry/geography types, spatial functions, and GiST indexing. |

| [postgis_topology](https://www.postgis.net/docs/Topology.html) | Topology data model for PostGIS. |

## Experimental extensions

Neon occasionally adds extensions that are in early development or undergoing validation. These are not recommended for production use.

To install an experimental extension, set the session variable first:

```sql
SET neon.allow_unstable_extensions = 'true';
```

Current experimental extensions include `pgrag` and `pg_mooncake`. Use them in a separate project, not in your production database.

## Request an extension

If the extension you need is not listed, you can request it. Neon reviews requests regularly and prioritizes them based on demand and compatibility. Open a request via the Neon Console or reach out on [Discord](https://discord.gg/92vNTzKDGp).

## Extension support

Neon makes third-party extensions available but does not maintain upstream extension code. If you find a bug in an extension, report it to the extension's upstream maintainers. Once a fix is released, Neon can update to the new version. You can request a version update by opening a [support ticket](https://console.neon.tech/app/projects?modal=support).
