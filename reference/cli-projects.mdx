---
title: "neonctl projects: manage projects via CLI"
description: "List, create, update, delete, recover, and inspect Neon projects from the terminal using the neonctl projects command and its subcommands."
---

The `neonctl projects` command lets you manage Neon projects from the terminal. A project is the top-level container for branches, databases, roles, and compute endpoints in Neon. You can list existing projects, create new ones, update project settings, delete projects, recover recently deleted projects, and retrieve details about a specific project.

<Note>
  Before running `projects` commands, [install the Neon CLI](/reference/neon-cli) and authenticate using `neon auth` or by setting a `NEON_API_KEY` environment variable.
</Note>

## Usage

```bash
neon projects <subcommand> [options]
```

| Subcommand | Description |
|---|---|
| [`list`](#list) | List projects |
| [`create`](#create) | Create a project |
| [`update`](#update) | Update a project |
| [`delete`](#delete) | Delete a project |
| [`recover`](#recover) | Recover a deleted project |
| [`get`](#get) | Get a project |

## list

Lists projects that belong to your Neon account, including any projects shared with you.

### Usage

```bash
neon projects list [options]
```

### Options

| Option | Description | Type |
|---|---|---|
| `--org-id` | List projects belonging to the specified organization | string |
| `--recoverable-only` | List only projects deleted within the recovery window | boolean |
| `--context-file` | Context file path and file name | string |

Along with these options, all [global options](/reference/neon-cli#global-options) are supported.

## create

Creates a new Neon project. Projects created via the CLI default to Postgres 17. To create a project with a different Postgres version, use the [Neon Console](https://console.neon.tech) or the [Neon API](https://api-docs.neon.tech/reference/createproject).

### Usage

```bash
neon projects create [options]
```

### Options

| Option | Description | Type |
|---|---|---|
| `--name` | Project name. Defaults to the project ID if not specified | string |
| `--region-id` | Region for the project. Defaults to `aws-us-east-2` | string |
| `--org-id` | Organization to create the project in. Defaults to your default organization | string |
| `--database` | Default database name | string |
| `--role` | Default role name | string |
| `--cu` | Compute size for the default branch. Fixed (e.g., `"2"`) or autoscaling range (e.g., `"0.5-3"`) | string |
| `--psql` | Connect to the new project via `psql` immediately after creation | boolean |
| `--set-context` | Set the new project as the current CLI context | boolean |
| `--block-public-connections` | Block connections from the public internet | boolean |
| `--block-vpc-connections` | Block connections using VPC endpoints | boolean |
| `--hipaa` | Enable the project for HIPAA compliance | boolean |
| `--context-file` | Context file path and file name | string |

Along with these options, all [global options](/reference/neon-cli#global-options) are supported.

### Examples

Create a project with a name in a specific region:

```bash
neon projects create --name mynewproject --region-id aws-us-west-2
┌───────────────────┬──────────────┬───────────────┬──────────────────────┐
│ Id                │ Name         │ Region Id     │ Created At           │
├───────────────────┼──────────────┼───────────────┼──────────────────────┤
│ muddy-wood-859533 │ mynewproject │ aws-us-west-2 │ 2023-07-09T17:04:29Z │
└───────────────────┴──────────────┴───────────────┴──────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────────────┐
│ Connection Uri                                                                       │
├──────────────────────────────────────────────────────────────────────────────────────┤
│ postgresql://[user]:[password]@[neon_hostname]/[dbname]                              │
└──────────────────────────────────────────────────────────────────────────────────────┘
```

Available `--region-id` values: `aws-us-west-2`, `aws-ap-southeast-1`, `aws-ap-southeast-2`, `aws-eu-central-1`, `aws-us-east-1`, `aws-us-east-2`, `azure-eastus2`.

Create a project and get full details in JSON format:

```bash
neon projects create --output json
```

Create a project and connect immediately via `psql`:

```bash
neon projects create --psql
```

Create a project, run a SQL file via `psql`, and set the new project as the current context:

```bash
neon projects create --psql --set-context -- -f dump.sql
```

<Tip>
  Use `neon connection-string` to extract a connection URI programmatically after creating a project. See [connection-string](/reference/neon-cli#commands).
</Tip>

## update

Updates settings for an existing Neon project. Identify the project by its ID, which you can find with `neon projects list` or on the **Settings** page in the Neon Console.

### Usage

```bash
neon projects update <id> [options]
```

### Options

| Option | Description | Type | Required |
|---|---|---|:---:|
| `--name` | New project name. Cannot be empty | string | yes |
| `--cu` | Compute size for the default branch's primary compute. Fixed (e.g., `"2"`) or range (e.g., `"0.5-3"`) | string | |
| `--block-public-connections` | Block or unblock public internet connections. Use `--block-public-connections=false` to unblock | boolean | |
| `--block-vpc-connections` | Block or unblock VPC connections. Use `--block-vpc-connections=false` to unblock | boolean | |
| `--hipaa` | Enable or disable HIPAA compliance for the project | boolean | |
| `--context-file` | Context file path and file name | string | |

Along with these options, all [global options](/reference/neon-cli#global-options) are supported.

### Examples

Rename a project:

```bash
neon projects update muddy-wood-859533 --name dev_project_1
┌───────────────────┬───────────────┬───────────────┬──────────────────────┐
│ Id                │ Name          │ Region Id     │ Created At           │
├───────────────────┼───────────────┼───────────────┼──────────────────────┤
│ muddy-wood-859533 │ dev_project_1 │ aws-us-west-2 │ 2023-07-09T17:04:29Z │
└───────────────────┴───────────────┴───────────────┴──────────────────────┘
```

Block public internet access (used with Neon's Private Networking feature):

```bash
neon projects update orange-credit-12345678 --block-public-connections=true
```

## delete

Deletes a Neon project. Identify the project by its ID. The deleted project's details are shown in the output. You can verify deletion by running `neon projects list`.

### Usage

```bash
neon projects delete <id> [options]
```

All [global options](/reference/neon-cli#global-options) are supported.

### Example

```bash
neon projects delete muddy-wood-859533
┌───────────────────┬───────────────┬───────────────┬──────────────────────┐
│ Id                │ Name          │ Region Id     │ Created At           │
├───────────────────┼───────────────┼───────────────┼──────────────────────┤
│ muddy-wood-859533 │ dev_project_1 │ aws-us-west-2 │ 2023-07-09T17:04:29Z │
└───────────────────┴───────────────┴───────────────┴──────────────────────┘
```

<Warning>
  Project deletion is permanent. Use `neon projects list --recoverable-only` to check whether a recently deleted project can still be recovered.
</Warning>

## recover

Recovers a project that was deleted within the deletion recovery window (typically 7 days). Use `neon projects list --recoverable-only` to find the project ID of a recoverable project.

### Usage

```bash
neon projects recover <id> [options]
```

All [global options](/reference/neon-cli#global-options) are supported.

### Example

```bash
neon projects recover crimson-voice-12345678
┌────────────────────────┬───────────┬───────────────┬──────────────────────┐
│ Id                     │ Name      │ Region Id     │ Created At           │
├────────────────────────┼───────────┼───────────────┼──────────────────────┤
│ crimson-voice-12345678 │ myproject │ aws-us-east-2 │ 2024-04-15T11:17:30Z │
└────────────────────────┴───────────┴───────────────┴──────────────────────┘
```

<Note>
  Not all project configuration is automatically restored. For details on what requires manual reconfiguration after recovery, see [Recover a deleted project](https://neon.tech/docs/manage/projects#recover-a-deleted-project).
</Note>

## get

Retrieves details about a specific Neon project. Identify the project by its ID.

### Usage

```bash
neon projects get <id> [options]
```

### Options

| Option | Description | Type |
|---|---|---|
| `--context-file` | Context file path and file name | string |

Along with these options, all [global options](/reference/neon-cli#global-options) are supported.

### Example

```bash
neon projects get muddy-wood-859533
┌───────────────────┬───────────────┬───────────────┬──────────────────────┐
│ Id                │ Name          │ Region Id     │ Created At           │
├───────────────────┼───────────────┼───────────────┼──────────────────────┤
│ muddy-wood-859533 │ dev_project_1 │ aws-us-west-2 │ 2023-07-09T17:04:29Z │
└───────────────────┴───────────────┴───────────────┴──────────────────────┘
```

Use `--output json` to see all available project fields:

```bash
neon projects get muddy-wood-859533 --output json
```
